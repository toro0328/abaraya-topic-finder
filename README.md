# あばらや話題帳

バイヤー高橋の動画やイベントから、Podcast「あばらや204号室R」の関連回と時間を探す非公式アーカイブです。

- 6秒ライブ／ジャズフェス／公開収録などの話題からPodcast回を探す
- 話題が中心の回を先に表示し、会話中に言葉が出ただけの回は折りたたんで下へ
- YouTube動画は関連候補があるものを初期表示。「候補なし」「すべて」に切り替え可能
- LISTENの時間から公式Podcast音声を再生
- 公式配信ページ・LISTEN文字起こし・YouTubeへ移動

公開されている公式RSS、LISTENのページ、YouTube公開情報から作ったデータを同梱しています。データは圧縮され、ブラウザ側で展開して読み込みます。全文音声・全文文字起こしは含みません。動画の候補は共通する語句によるもので、動画内で話していると確認済みではありません。

## GitHub Pages

GitHub Actionsから静的ファイルを公開します。`main`へのpushで `.github/workflows/pages.yml` が実行されます。

## X API料金の値上げ通知

`bot/x_api_price_watch.py` はX公式の料金ページにある「Post: Create」の料金を1日1回確認します。現在の基準額より高くなった場合だけ、Xアカウントから値上げを知らせる投稿を1回行い、基準額を更新します。価格情報を安全に読み取れない場合は投稿せず、Actionsを失敗として記録します。手動実行は `dry_run=true` が初期値です。
